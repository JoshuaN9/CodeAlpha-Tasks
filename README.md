# CodeAlpha CYBER SECURITY INTERNSHIP TASKS
A collection of hands-on cybersecurity projects completed as part of the CodeAlpha Cyber Security Internship.

# Projects
# Task 1: Basic Network Sniffer
A Python-based network packet capture and analysis tool built with Scapy. It displays packet details, identifies protocols, summarizes captured traffic, and exports results to CSV.

# Task 2: Phishing Awareness Training
Educational material covering phishing techniques, suspicious messages, social engineering, prevention practices, practical scenarios, and a knowledge-check quiz.

# Task 3: Secure Coding Review
A Python source-code review demonstrating common authentication and database security weaknesses, recommended remediations, and verification tests.

# Technologies
- Python
- Scapy
- SQLite
- Git and GitHub
- Markdown
